# Calculator App

A straightforward Android calculator for everyday arithmetic.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number input
- Percentage conversion
- Backspace and clear actions
- Chained calculations
- Divide-by-zero error handling
- Cleaned result formatting without unnecessary trailing zeroes

## Built with

- Java
- Android Views and XML layouts
- Android SDK 24+

## Run locally

1. Clone this repository.
2. Open it in Android Studio.
3. Allow Gradle to sync.
4. Run the app on an emulator or Android device.

## Project structure

`MainActivity` manages button input, calculator state, arithmetic evaluation, and display updates.
